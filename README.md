# 문맥 속 한 글자 — JLPT 스타일 빈칸채우기

이미지도 오디오도 필요 없는 순수 텍스트 퀴즈라 다른 두 게임보다
훨씬 가볍게 올릴 수 있어요

## 파일 구성

```
index.html          게임 본체 (건드릴 일 거의 없음)
jlpt-questions.js    문제 데이터 ← 여기만 편집하면 됩니다
```

폴더가 따로 필요 없어요 — 파일 2개만 저장소에 올리면 끝이에요
(기존 japanese-quiz나 music-quiz 저장소에 같이 넣어도 되고,
새 저장소를 만드셔도 돼요)

## 조작법

| 키 | 동작 |
|---|---|
| `P` | 문제표 열기 / 닫기 |
| `Space` / `Enter` | 정답 공개 (정답 초록색 강조 + 해설) |
| `←` / `→` | 이전 / 다음 문제 |
| `1` / `2` | 각 팀 +1점 |
| `Shift`+`1` / `2` | 각 팀 −1점 |

## 문제 추가하기

`jlpt-questions.js` 를 열어서 아래 형식으로 추가하면 끝입니다

```js
{
  id: "21",
  level: "N3",              // N5 / N4 / N3 / N2 / N1
  sentence: "その＿＿は美しい。",   // 빈칸은 반드시 ＿＿ (전각 밑줄 2개)
  meaning: "그 ___은 아름다워요. (경치)",
  options: ["景色", "景食", "影色", "警色"],
  answer: 0,                // 정답 인덱스 (0부터 시작)
  note: "景色(경치)의 景이 맞아요 — 나머지는 비슷하게 생겼지만 다른 뜻이에요"
},
```

- `sentence`의 `＿＿` 자리에 정답 공개 시 정답 단어가 자동으로 들어가요
- 선택지는 꼭 4개, `answer`는 그중 정답의 순서(0=첫번째)예요
- `note`는 정답 공개 후 아래에 뜨는 해설이에요 — 왜 헷갈리는지 설명해주면
  다들 "아~" 하면서 공부도 되고 재밌어해요
